1. esh_、ESH_という接頭辞をファイル名、変数名、関数名、構造体定義、マクロ定義からなくしてください。
2. file と pipe は可能な限り UNIX V7 の file.h, pipe.h, pipe.c の実装と同じにしてください。
3. UNIX V7 には file.c というソースファイルはないので、UNIX V7 と同じ名前のソースファイルを作成して、そのファイルで UNIX V7 と同じ関数、変数、マクロを定義してください。
4. inode 構造体は UNIX V7 と同様に inode.h で定義して `C:\usr\src\MCUFW\src\core\sys\h` に配置してください。
