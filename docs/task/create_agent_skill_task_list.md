### request
tasklist スキルを作成してください。

### 使い方
$tasklist 10
意味 => `/docs/task_list.md` の 10 番のタスクを実行する

### task_list.md の配置場所
`/docs/task_list.md`

### open/close マーク
Legend:
[o]: open
[c]: close
タスクが完了したらマークを `o` から `c` に変更する。

### 特殊動作
下記の依頼の場合は、`task_list.md` の `## note` セクションに回答を記録する。
- 教えてください
- 調べてください
- まとめてください、要約してください
